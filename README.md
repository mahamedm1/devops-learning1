## 🐧 Linux

I started my DevOps journey by building a foundation in Linux and becoming comfortable working from the command line.

### Topics Covered

* Terminal and Linux commands
* Manual pages and command documentation
* Shells, Bash and Zsh
* Linux filesystem and directory structure
* File and directory management
* Working with filenames containing spaces
* Vim and terminal-based text editing
* `sudo` and the root user
* Users and groups
* File permissions 
* Symbolic and octal permissions
* File and directory ownership
* Standard input, output and error
* Environment variables
* Aliases
* Linux troubleshooting and debugging

### 🎮 OverTheWire Bandit

I also used **OverTheWire Bandit** to reinforce Linux concepts through hands-on challenges.

This gave me practical experience with:

`ssh` • `find` • `grep` • `sort` • `uniq` • `strings` • `base64` • `tr` • `pipes` • `redirection` • `permissions` • `file searching` • `telnet`

## 📜 Bash Scripting

After building a foundation in Linux, I moved into Bash scripting to learn how to automate tasks and combine Linux commands into reusable scripts.

### Topics Covered

* Variables and parameters
* Positional parameters
* Arithmetic expansion
* Conditional statements with `if`, `elif` and `else`
* Nested conditionals
* `while` loops
* `for` loops
* Flow control with `break` and `continue`
* Functions and function parameters
* User input
* Input validation and handling bad data
* Pipes and redirection
* Error handling and exit codes
* Environment variables and `$PATH`
* Working with files and directories

### 🛠️ Bash Practice

Alongside the lessons, I wrote small scripts and exercises to practise using these concepts together, including:

* Processing command-line arguments
* Validating user input
* Searching files and logs
* Checking files and directories
* Using conditions and loops
* Combining Linux commands within scripts
* Basic task automation
